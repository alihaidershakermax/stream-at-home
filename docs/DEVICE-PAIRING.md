# Link another device with QR

TMPlayer uses Telegram's official QR sign-in. The QR code authorizes the new TMPlayer installation as another session of the Telegram account you choose; it does not copy a session token from one app to another.

## On the device you are adding

Open TMPlayer on the TV or computer; its sign-in screen shows a QR code first. On a phone, start at the phone-number screen and choose **Scan a QR code instead**. Keep the code visible. If it expires, TMPlayer refreshes it or offers a new one.

## On a phone already signed in to the account you want

In Telegram, open **Settings → Devices → Link Desktop Device**, then scan the code shown by TMPlayer. Telegram may ask you to confirm the new session or enter your two-step verification password on the new device.

Once authorized, the new TMPlayer installation uses that same Telegram account and its chats. If a different account should be linked, scan with a phone signed in to that account instead. Only scan a code displayed by a device you are setting up.
